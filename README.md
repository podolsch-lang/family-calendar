# 우리 가족 캘린더

아빠, 엄마, 하윤이 휴대폰으로 같이 보는 달력입니다. 교대 근무표도 여기에 두고, 나중에 두 사람이 하나의 Google 캘린더로 맞춰 볼 수 있습니다.

주소는 [https://podolsch-lang.github.io/family-calendar/](https://podolsch-lang.github.io/family-calendar/) 입니다. 설치 프로그램은 없고, 브라우저에서 홈 화면에 추가해서 씁니다.

## 이렇게 써요

1. 휴대폰 브라우저로 위 주소를 엽니다.
2. **달력**에서 날짜를 누르고 ＋ 버튼으로 일정을 넣습니다. 누구의 일정인지, 종일인지, 반복인지를 고를 수 있습니다.
3. 이름 칩을 누르면 그 사람 일정만 숨기거나 다시 볼 수 있습니다.
4. 위쪽의 **월 / 주 / 일**로 보는 방식을 바꿉니다. 오늘은 동그라미로 표시되고, 일요일과 공휴일은 빨간색, 토요일은 파란색입니다.
5. **근무**에서 근무 종류와 순환을 만듭니다.
6. **설정**에서 이름과 색을 바꾸고, 버전을 확인합니다.

Google을 연결하기 전에는 모든 내용이 **이 휴대폰 안에만** 저장됩니다. 앱을 지워도 휴대폰의 사이트 데이터를 지우면 일정도 함께 사라지니, 두 사람이 같이 쓸 거면 아래 Google 연결을 해 주세요.

## 근무표

근무 패턴은 앱 안에 저장하고, 언제든 고칠 수 있습니다. 코드에 박아 두지 않습니다.

- **근무 종류**: 이름, 달력에 보일 짧은 글자, 색, 시작·끝 시간. 쉬는 날은 시간을 비울 수 있습니다.
- **순환**: 근무 종류를 원하는 만큼 이어 붙입니다. `주 → 야 → 비 → 비`처럼 같은 근무를 여러 번 넣어도 됩니다.
- **시작일**: 그 날의 근무가 순환의 첫날입니다. 미리보기로 요일이 맞는지 확인하세요.
- **패턴이 바뀌면**: 예전 패턴을 지우지 말고, 바뀌는 날로 **새 패턴**을 추가하세요. 그 날짜 이후만 새 순환을 따르고, 그 전 달은 그대로입니다.
- **하루만 바꾸기**: 연차, 반차, 교육, 다른 근무로 그날만 바꿉니다.
- 기본으로 고를 수 있는 예시: **4조2교대 주야비비**, **3교대**, **2교대**. 고른 뒤 자유롭게 고치면 됩니다.

월 달력의 각 날짜에는 짧은 글자가 색 배지로 붙습니다.

## 홈 화면에 추가

- **Android Chrome**: 메뉴(⋮) → 홈 화면에 추가 또는 앱 설치. 설정 화면에 버튼이 뜨면 그 버튼을 눌러도 됩니다.
- **아이폰 Safari**: 공유 버튼 → 홈 화면에 추가. 이름은 ‘가족캘린더’로 올라갑니다.

추가한 뒤에는 브라우저 주소창 없이 앱처럼 열립니다.

## 사이트를 켜는 방법 (GitHub Pages)

저장소 주인만 한 번 하면 됩니다.

1. GitHub 저장소 → **Settings** → **Pages**.
2. **Build and deployment**의 Source를 **GitHub Actions**로 고릅니다.
3. `main`에 올린 뒤 **Actions** 탭에서 “Deploy GitHub Pages”가 성공하는지 봅니다.
4. 주소는 `https://podolsch-lang.github.io/family-calendar/` 입니다.

Actions 대신 브랜치에서 바로 배포하려면 Source를 **Deploy from a branch**, 브랜치를 `main`, 폴더를 `/ (root)`로 두면 됩니다. 그 경우에는 위 워크플로와 동시에 켜 두지 않는 편이 좋습니다. 워크플로 파일을 쓰는 쪽을 권합니다.

파일은 빌드 없이 그대로 올라갑니다. 경로는 상대 경로라서 이 주소의 하위 폴더에서도 동작합니다.

## Google 캘린더와 같이 쓰기

두 휴대폰이 같은 일정을 보게 하려면 Google 공유 캘린더를 연결합니다. 연결 전에는 앱이 그대로 동작하고, 위쪽에 안내 배너가 나옵니다.

준비 순서는 [docs/GOOGLE_SETUP.md](docs/GOOGLE_SETUP.md)에 적어 두었습니다. 개발자가 아니어도 따라 할 수 있게 썼습니다.

연결한 뒤 **동기화**를 누르면:

- 일반 일정은 Google 캘린더와 주고받습니다. 누구의 일정인지는 일정 안에 표시해 두어 색이 유지됩니다.
- 근무 일정은 따로 표시해 두었다가, 패턴이 바뀌면 그 기간(대략 지난 한 달부터 앞으로 4개월)만 지우고 다시 넣습니다. 일반 일정은 그대로 둡니다.
- 근무 종류, 패턴, 하루 변경, 가족 이름과 색은 공유 캘린더 안의 설정 일정에 넣어 두 휴대폰이 같이 받습니다.

## 폴더

| 파일 | 역할 |
| --- | --- |
| `index.html`, `css/`, `js/` | 앱 화면 |
| `config.js` | Google 클라이언트 ID. 비어 있으면 휴대폰에만 저장 |
| `version.js`, `sw.js` | 버전과 오프라인 캐시 |
| `manifest.json`, `icons/` | 홈 화면 설치 정보 |
| `docs/GOOGLE_SETUP.md` | Google 연결 순서 |

## 버전

지금 버전은 **1.0**입니다. 설정 화면 아래에 작게 나옵니다. 다음 배포는 0.1씩 올립니다.

## 로직 확인

브라우저 없이 근무 계산과 캘린더 변환을 확인하려면:

```bash
node tests/logic.test.mjs
```

화면 확인용 스크립트는 `tests/smoke.mjs`입니다. 앱을 띄운 뒤 `APP_URL`을 넘겨 실행하며, 실행하려면 `puppeteer-core`가 따로 필요합니다. 앱을 쓰는 데는 필요 없습니다.
